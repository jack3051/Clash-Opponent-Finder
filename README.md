# Problem it solves:
This is a tool that can be used in Clash Royale to scan an opponent's name to find them on RoyaleAPI.
This is better than searching the name because often times it is faster to type (takes 2-3 seconds) and can type any emoji / international language symbols.

# How it works:
You take a picture of the opponent's name on your computer's webcam.
It then create a png image of your name and sends it to Gemini 3.1-flash-lite along with a prompt to extract the name from the image.
It then redirects you to the RoyaleAPI search bar of the opponent where you can find the opponent and then look at their battle log to see their previous decks used.

# How I used it:
I used it on the ranked gameode in clash royale to acheive a top #510 rank global. It is early season so it is easier to acheive than during the last days of the season.
